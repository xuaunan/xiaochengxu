# Abandoned Project Notice

Date: 2026-06-07

Status: abandoned / no longer under active development.

This directory contains an experimental Sunshine Travel desktop client. The direction has been intentionally stopped because ride-hailing on a desktop computer is not a natural product scenario and is not worth further investment for the current project.

Keep this folder only as an archive of prior exploration:

- Electron + Vue desktop experiment
- Passenger, driver, and operations feature-mapping notes
- UI/interaction experiments and screenshots
- Build and verification history

Do not treat this project as part of the active Sunshine Travel delivery path unless the owner explicitly reopens it later.
