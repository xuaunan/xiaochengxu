# 阳光出行后端优化清单

## 本次修复与重构

- 统一接口返回结构为 `code`、`msg`、`data`，全局异常统一映射业务错误码，避免堆栈直接暴露给前端。
- 新增 `ErrorCode`、分页结果对象、订单/支付/优惠券/顺风车/提现等状态常量，减少魔法字符串与状态散落问题。
- 接入 JWT 过滤器与注解式权限拦截器，所有非公开接口按 `USER`、`DRIVER`、`ADMIN` 做角色边界控制。
- 注册、登录、实名、司机资质、提现、优惠券创建发放、订单创建/取消/支付等关键请求均补齐参数校验。
- 订单流程改造成严格状态机：`DISPATCHING -> ACCEPTED -> PICKING_UP -> IN_TRIP -> FINISHED`，禁止非法跳变。
- 接单增加短时幂等锁，防止司机高并发抢单重复成功；下单增加同路线进行中订单去重。
- 计费逻辑补齐基础价、里程费、时长费、夜间附加费、远途附加费、国际汇率换算与顺风车折扣。
- 订单取消增加违约金规则，优惠券绑定、核销、回退逻辑闭环，支付后触发司机收益结算。
- 顺风车增加发布校验、座位控制、重复申请拦截、车主确认、乘客确认与取消回座逻辑。
- 优惠券增加模板创建、用户领取、管理员发放、领取上限、库存校验、过期失效与操作日志追踪。
- 管理后台增加用户、司机、订单、优惠券、提现、操作日志分页查询与模糊筛选。
- 补齐司机工作台、资质提交流程、车辆审核字段、实时位置更新与轨迹上报/查询能力。
- 新增消息推送记录表，覆盖订单创建、接单、接驾、完单、支付、优惠券到账等业务场景。
- 新增财务汇总、司机收益累计、提现审核与驳回回退逻辑，金额全部使用 `BigDecimal`。

## 新增数据库初始化能力

- 新增 `schema.sql`：创建用户、司机、订单、顺风车、支付、优惠券、轨迹、消息、日志等全量表结构。
- 新增 `data.sql`：初始化管理员、乘客、司机、车型、优惠券、用户券等预置数据。
- 更新 `application.yml` 启用 SQL 自动初始化，数据库导入后即可直接启动。
