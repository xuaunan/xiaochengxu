# 测试用例与验收清单

## 1. 普通用户

1. 使用 `13800000001 / 123456` 登录，首页可看到车型与活动。
2. 创建即时打车订单后，订单列表中出现新订单。
3. 对未支付订单执行支付确认，支付状态从 `UNPAID` 变为 `PAID`。
4. 进入顺风车页面，可发布验证行程并申请同行。
5. 优惠券页能看到已发放券列表。

## 2. 司机

1. 使用 `13900000001 / 123456` 登录司机端。
2. 切换到在线接单后，工作台展示最新状态。
3. 进入订单池可查看 `DISPATCHING` 状态订单并完成抢单。
4. 提交提现申请后，后台数据库中生成提现记录。

## 3. 管理员

1. 管理端点击“管理员快捷登录”。
2. 数据大盘显示用户、司机、订单、交易额等核心指标。
3. 用户、司机、订单、优惠券页面均能正常加载。

## 4. 项目验收建议问答点

1. 为什么使用 JWT：适合多端分离和无状态接口鉴权。
2. 为什么引入 Redis：用于缓存验证码、会话、模板消息和后续风控扩展。
3. 如何解决支付资质问题：使用支付确认单据，不影响业务闭环展示。
4. 如何处理地图能力限制：使用微信原生位置能力和路线参数完成验证。
