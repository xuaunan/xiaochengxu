# 阳光出行小程序前端运行说明

## 目录说明

- `sunshine-user-miniapp`
  - 用户端微信原生小程序
  - 含欢迎页、登录页、首页地图、打车全流程、顺风车、国际出行、订单、优惠券、个人中心及配套页面
- `sunshine-driver-miniapp`
  - 司机端微信原生小程序
  - 含司机入驻、听单地图、行程管理、收益、消息、设置等完整页面

## 微信开发者工具导入步骤

### 1. 导入用户端

1. 打开微信开发者工具
2. 选择“导入项目”
3. 项目目录选择 `D:\xiaochengxu\sunshine-user-miniapp`
4. `AppID` 可先填写测试号或使用“无 AppID 体验”
5. 点击导入后等待编译完成

### 2. 导入司机端

1. 再次打开“导入项目”
2. 项目目录选择 `D:\xiaochengxu\sunshine-driver-miniapp`
3. `AppID` 同样可使用测试号或无 AppID 体验
4. 点击导入后等待编译完成

## 必要配置

### 用户端

- 已在 `app.json` 中配置定位权限说明

### 司机端

## Mock 与接口说明

- 当前前端默认使用本地 Mock 数据
- 用户端已封装 `utils/request.js`
- 司机端已封装 `utils/request.js`
- 如后续要对接真实后端，可将：
  - `app.js` 中的 `useMock` 改为 `false`
  - `baseUrl` 改为真实后端地址

## 地图与轨迹说明

- 用户端首页、司机接驾页、行程中页均使用微信原生 `map` 组件
- 已内置：
  - 起点、终点、司机、用户定位标记
  - 路线折线展示
  - 司机接驾轨迹
  - 行程进行轨迹
- 无需第三方地图 Key，即可完成项目验收验证

### 司机端轨迹模式

司机端“我的 -> 接单设置”中可以切换轨迹模式：

- 规划轨迹：默认模式。司机接单后不读取司机真实位置，而是在上车点附近生成司机位置，优先按地图道路规划路线推进小车位置，并按每 1.5 公里约 1 分钟的速度规划行驶；随机红灯会让车辆暂停、时间继续增加。用户端、司机端和管理后台都能查看同一套轨迹进度，管理后台只展示行驶时长、距离和进度，不展示具体经纬度。
- 真实定位：司机端调用 `wx.getLocation` 获取司机手机实际位置，并将真实经纬度上报给后端，用户端、司机端、管理后台和数据库同步显示真实轨迹。

本轮详细改动见：`docs/change-log-2026-05-14.md`

## 常见问题

### 1. 地图不显示定位

- 检查开发者工具是否开启定位测试
- 检查项目是否允许定位权限
- 即使没有定位，用户端首页也支持手动输入地址验证

### 2. 点击按钮没反应

- 先确认当前页面是否完成编译
- 若是首次导入，建议点击开发者工具“编译”
- 检查控制台是否存在缓存问题，可勾选“不校验合法域名”等开发设置后重新编译

### 3. 为什么没有真实支付

- 本项目按项目验收要求提供完整支付确认方案
- 无需商户号，也不会影响全流程验证和验收效果

### 4. 为什么没有真实派单服务

- 当前已用本地 Mock 数据内置智能派单、司机接驾与轨迹更新
- 可以在没有后端联调的情况下稳定完成验证
